# New Direction Group 留學顧問網站

這是 New Direction Group 的官方網站，提供留學諮詢、課程推薦等服務。

## 功能特點

- 留學資訊分享
- 課程推薦
- 成功案例分享
- 線上諮詢服務

## 技術架構

- HTML5
- CSS3
- JavaScript
- 響應式設計

## 本地開發

1. 克隆儲存庫：
```bash
git clone https://github.com/您的使用者名稱/Newdirection-Webpage.git
```

2. 開啟專案資料夾：
```bash
cd Newdirection-Webpage
```

3. 使用瀏覽器開啟 index.html 即可預覽網站。
